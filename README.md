# Personal site

Plain HTML + one stylesheet (`style.css`). No build step — open `index.html` in a browser.

| To change...   | Edit |
|----------------|------|
| Your name      | search all files for `Your Name` |
| Photos         | put images in `img/` and change the `src` in `cv.html` |
| CV             | `cv.html` — each `<div class="item">` is one entry; copy/paste to add |
| Reading list   | `reading.html` — one line per book (Goodreads link, title, author); move lines between Currently reading / Next up / Read |
| Colours        | the variables at the top of `style.css` |
| Glows          | the "THE GLOW" section of `style.css` — each page has its own blob sizes/positions/colours |

**Publishing (free):** push this folder to a GitHub repo and turn on GitHub Pages,
or drag the folder onto Netlify / Cloudflare Pages.
